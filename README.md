# АИС «Справки» — учёт заявок студентов на получение справок

Программная часть ВКР Полывянного А.М. (09.03.02, «Веб-разработка»):
веб-приложение на Python Flask + SQLite + Jinja2/Bootstrap 5.
Все данные демонстрационные и вымышленные.

## Запуск на macOS

```bash
cd "Семестр 9 (осень 2026)/ВКР (защита 2026-12-28)/Программа АИС"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python seed.py            # создать instance/ais.sqlite3 с демо-данными на 04.11.2026
python run.py             # http://127.0.0.1:5000
```

Альтернатива `python run.py`: `flask --app run run`. Интернет не нужен:
Bootstrap 5.3.3 и шрифты лежат в `app/static/`.

## Что умеет (кратко)

- Единый реестр заявок деканата: студент подаёт заявку в АИС сам, а заявки,
  принятые через ЕЛК, МФСО или куратора, сотрудник регистрирует в реестре
  («Зарегистрировать заявку», канал и № заявки в канале). Реестр, CSV и отчёт —
  с отбором и сводкой по каналам.
- Плановая дата по рабочим дням, 6 статусов, контроль просрочки.
- Печать и PDF справок по шаблону; справка-вызов — по форме приказа
  Минобрнауки России от 19.12.2013 № 1368 (ФИО в дательном падеже —
  подсказка, проверяет сотрудник; основание и период — по учебному графику),
  выдаётся только на бумаге.
- Разбор обращения свободным текстом (письмо, сообщение куратора, запись МФСО)
  локальной языковой моделью на сервере вуза (llama.cpp `llama-server`; выбрана
  Qwen3-30B-A3B-Instruct-2507 — замеры в `docs/ЛОКАЛЬНАЯ-ИИ-ЗАМЕР-2026-11-12.md` и
  `docs/ЛОКАЛЬНАЯ-ИИ-ЗАМЕР-2026-11-13.md` в корне репозитория).
  Модель только заполняет форму регистрации: ответ ограничен JSON-схемой и белым
  списком, заявку создаёт сотрудник после проверки; текст обращения не сохраняется,
  в журнал — только факт и исход. Без `AIS_LLM_URL` блок скрыт, всё работает вручную.
- Проверка «вид справки ↔ цель» той же моделью: команда `flask --app run check-types`
  (по расписанию) проверяет новые заявки и при явном расхождении («Справка об обучении»
  «для военкомата») показывает сотруднику в реестре значок «ИИ: проверить вид», а на
  странице заявки — какой вид, возможно, нужен. Модель ничего не меняет и студенту не
  видна; студент при подаче модель не ждёт; модель видит только цель, а не выбор студента.
  Замер — `docs/ЛОКАЛЬНАЯ-ИИ-ВИД-ЦЕЛЬ-2026-11-13.md`: на независимом наборе пороги пройдены, по всем
  120 парам поймано 60/60 ошибочных выборов, но лишняя подсказка — у 10 % верных заявок (половина —
  «инъекции» в тексте цели). Включать — в опытном режиме, по решению владельца.

## Проверка «вид ↔ цель» по расписанию

**Опытный режим** — см. итог замера выше; включение — решение владельца.

Таблица `type_checks` в БД прежней версии создаётся сама при запуске программы
(`db.create_all()` в `create_app`: существующие таблицы и данные не меняются). Затем,
например, cron на сервере АИС раз в 5 минут:

```
*/5 * * * * cd /opt/ais && AIS_LLM_URL=http://127.0.0.1:8081 .venv/bin/flask --app run check-types >> logs/check-types.log 2>&1
```

Без `AIS_LLM_URL` команда пишет «выключена» и завершается с кодом 0; если модель
недоступна — код 1, в журнале аудита `LLM_TYPE_CHECK fail …`, непроверенные заявки
будут проверены при следующем запуске.

## Состав

- `app/__init__.py` — фабрика `create_app`, команды `flask --app run init-db`, `flask --app run backup-db`,
  `flask --app run check-types [--limit 20]`.
- `app/models.py` — 9 таблиц: roles, users, students, cert_types, statuses, requests, status_history, audit_log,
  type_checks (итог проверки «вид ↔ цель», без текста цели; с 13.11.2026).
- `app/config.py` — настройки и производственный календарь (праздники 2026–2040, переносы по ч. 2 ст. 112 ТК РФ — `weekend_holiday_transfers`).
- `app/workdays.py` — расчётный модуль (плановая дата по рабочим дням).
- `app/services.py` — нумерация ГГГГ-NNNNN, создание заявки, граф переходов статусов; переход не выполняется, если статус
  успел сменить другой сотрудник (форма передаёт статус, который он видел, а запись — условный UPDATE).
- `app/security.py` — вход, блокировка после 5 попыток, `role_required`, аудит, заголовки безопасности.
- `app/reports.py`, `app/certificate.py`, `app/forms.py`, `app/views/{auth,student,staff,admin}.py`.
- `app/llm.py` — запросы к локальной модели (OpenAI-совместимый API, JSON-схема): разбор обращения
  с белым списком ответа и проверка «вид ↔ цель» (`check_type` — подходящие виды по цели,
  пометку ставит `type_verdict`).
- `app/type_check.py` — фоновая проверка новых заявок для `flask check-types`.
- `tools/llm_eval.py`, `tools/llm_eval/appeals.jsonl` — оценка разбора на 60 вымышленных обращениях;
  `tools/type_eval.py`, `tools/llm_eval/purposes*.jsonl` — оценка «вид ↔ цель» (60 + 30 + 30 пар);
  результаты прогонов — `tools/llm_eval/results/`.
- `seed.py` — демо-данные через те же функции `services.py`.
- `tests/` — pytest; `tools/` — скрипты проверок, скриншотов, рисунков, листинга.

## Настройки (переменные окружения)

| Переменная | Назначение |
|---|---|
| `AIS_SECRET_KEY` | секрет сессии и CSRF; если не задан, при первом запуске создаётся случайный ключ в `instance/secret.key` (права 600) |
| `AIS_DATABASE` | путь к файлу SQLite (по умолчанию `instance/ais.sqlite3`) |
| `TZ` | часовой пояс сервера — `Europe/Moscow`: отсечка 17:00 и «сегодня» в плановой дате считаются по местному времени сервера |
| `AIS_DATABASE_URL` | полная строка подключения SQLAlchemy к другой СУБД, например `postgresql+psycopg://user:pass@host/ais` (нужен драйвер; `flask backup-db` в этом случае не работает — используйте `pg_dump`) |
| `AIS_HTTPS=1` | cookie сессии только по HTTPS (за обратным прокси с TLS) |
| `AIS_ACCREDITATION` | строка справки-вызова о государственной аккредитации (кем выдана, реквизиты) — задаётся при внедрении |
| `AIS_EXTRA_HOLIDAYS` | дополнительные нерабочие дни `ГГГГ-ММ-ДД,…` — переносы январских праздников из постановления Правительства РФ на следующий год (перенос праздника, выпавшего на выходной, по ч. 2 ст. 112 ТК РФ считается сам) |
| `AIS_LLM_URL` | адрес `llama-server` локальной модели, например `http://127.0.0.1:8081`; пусто — разбор обращений выключен |
| `AIS_LLM_TIMEOUT` | таймаут запроса к модели, с (по умолчанию 30: Qwen3-30B-A3B на RX 580 + ОЗУ отвечает до ≈15 с) |
| `AIS_LLM_MODEL` | имя модели для журнала аудита (по умолчанию `local`) |
| `AIS_HOST`, `AIS_PORT`, `AIS_DEBUG` | параметры `run.py` |

Признак просрочки считается от текущей даты, поэтому при запуске позже
04.11.2026 просроченных заявок в демо-данных будет больше; `python seed.py ГГГГ-ММ-ДД`
строит демо-данные на другую опорную дату.
